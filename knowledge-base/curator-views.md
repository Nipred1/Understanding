# Представления для куратора

## Карточка проекта на дату созвона

- позиции по цели, потребителю и сценарию;
- статус темы: обсуждалась / не обсуждалась / неизвестно;
- сравнение: согласованность, частичное расхождение, сильное расхождение или недостаточно данных;
- изменение относительно предыдущего сопоставимого созвона;
- причины сигнала и ссылки на подтверждающие фрагменты;
- оценка куратора и история внимания, если они есть.

## История участника

Позиции конкретного участника по каждой теме во времени, включая новые формулировки, явные изменения и моменты, когда позицию определить не удалось.

## Очередь внимания

Активные проекты, отсортированные по силе/устойчивости расхождения и давности сигнала. Порог «сильного расхождения» на старте настраивается и проверяется с кураторами, а не считается установленным фактом.

## Сводка созвона

Найденные позиции, аргументы, решения, отказы и открытые вопросы с переходом к источнику.

## Пример отображения

Для проекта «Приложение для онлайн-записи в мастерскую»:

- **3 октября:** Анна говорит о приложении для записи клиентов, Борис — о данных клиентов; Вика цель не называет. По цели есть расхождение; отсутствие позиции Вики не считается несогласием. По потребителю Анна называет клиентов, Борис — владельца мастерской.
- **10 октября:** формулировка Бориса сближается с позицией Анны, Вика впервые называет цель и соглашается. По сценарию обсуждается выбор времени в приложении и уведомление мастера.
- **17 октября:** после разговора с заказчиком сценарий меняется на запись через мессенджер, Анна и Вика принимают изменение. Цель близка у всех троих; расхождение по потребителю сохраняется.

Карточка проекта показывает актуальное расхождение по потребителю и позволяет открыть связанные высказывания и фрагменты всех трёх созвонов.
